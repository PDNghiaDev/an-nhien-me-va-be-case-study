# Chặng 11 — GitHub, Cloudflare và địa chỉ xem thử

## Đã thực hiện

- Cấu hình static export được kế thừa từ Starter.
- Build và kiểm tra bản `out/` trên localhost.
- Đã tạo và push repository công khai: https://github.com/PDNghiaDev/an-nhien-me-va-be-case-study
- Đã kết nối nhánh `main` với Cloudflare Pages; mỗi commit mới tự kích hoạt build.
- Cấu hình build: `npm run build`; thư mục đầu ra: `out`.
- URL preview HTTPS: https://an-nhien-me-va-be-case-study.pages.dev
