# An Nhiên Mẹ & Bé — Website AI Starter Case Study

Case study hư cấu được xây dựng theo lộ trình 13 chặng của khóa Website AI Starter.

Website minh họa dịch vụ chăm sóc mẹ và bé tại nhà, tập trung vào sự minh bạch của người thực hiện,
phạm vi dịch vụ, quy trình và ranh giới với dịch vụ y tế. Đây không phải doanh nghiệp đang hoạt động.

## Chạy trên máy

```bash
npm install
npm run dev
```

## Build tĩnh

```bash
npm run build
npm run start
```
